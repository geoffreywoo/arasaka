# Asset Attribution

## Restored Empire Refresh

Seven coordinated original AI-generated concept scenes were created with OpenAI image generation for this project on 2026-10-03 (local time). They are visual reconstructions, not official screenshots, extracted game models, certified product photography, or exact reproductions of in-game silhouettes.

| Asset family | Depiction / scope |
| --- | --- |
| `headquarters-v3-*` | Speculative Tokyo headquarters, architecture and plaza |
| `relic-v3-*` | Reconstructed neural cartridge, not a validated Relic model |
| `mikoshi-v3-*` | Speculative archive facility; no claim to depict official interior architecture |
| `shingen-v3-*` | TKI-20-inspired smart submachine-gun concept silhouette |
| `yukimura-v3-*` | HJKE-11-inspired smart-pistol concept silhouette |
| `security-v3-*` | Speculative logistics/protective operations; generated insignia removed in a follow-up edit |
| `banking-v3-*` | Speculative Tokyo private-bank environment |

Original PNGs are in `source/`; prompts and the security cleanup are recorded in `generation-inputs.json`. WebP/JPEG derivatives, mobile product compositions, and 28 `social/*.jpg` cards are prepared by `scripts/prepare-images.mjs`. Social cards overlay the supplied identity assets separately; the image model was instructed not to reproduce logos. Reconstructed weapons are decorative fictional illustrations, not engineering or deployment references.

The public refresh uses these seven scenes and the supplied identity assets. Older media below remains historical repository material and is not referenced by the new public pages.

`icons.svg` vendors Menu, X, and ArrowUpRight from Lucide. Preserve [LUCIDE-LICENSE.txt](LUCIDE-LICENSE.txt), including the inherited Feather license notices, when redistributing those icons. They are the only separately licensed software assets in this visual set.

The MIT code license does not grant third-party trademark, character, setting, press-image, or identity-artwork rights and does not automatically cover generated/composite media. A new depiction does not establish a right to use a referenced trademark. No commercial asset license or official approval is represented here.
